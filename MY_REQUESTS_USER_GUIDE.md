# My Requests Feature - Quick Start Guide

## 🚀 Getting Started

### For Users

#### Step 1: Login
1. Go to the application
2. Click "Login"
3. Enter your credentials
4. Click "Sign In"

#### Step 2: Access My Requests
1. Once logged in, look at the navbar
2. Click on **"My Requests"**
3. You'll be taken to your requests page

#### Step 3: View Your Requests
- **See all your appointment requests** in a clean card layout
- **View status** with colored badges:
  - 🟢 **Green (Approved)** - Your request was approved
  - 🔴 **Red (Rejected)** - Your request was declined
  - 🟡 **Yellow (Pending)** - Waiting for doctor's response

#### Step 4: Filter Requests
Use the filter buttons to see specific requests:
- **ALL** - See everything
- **PENDING** - Waiting for response
- **APPROVED** - Doctor approved
- **REJECTED** - Doctor declined

#### Step 5: View Details
Each request card shows:
- Doctor's name and specialty
- Appointment date
- Appointment time
- Reason for visit
- Payment status
- When you submitted it
- Request ID
- Doctor's contact info

## 📊 Understanding Status Badges

### Approved ✅
```
Status: APPROVED [Green Badge]
What it means: Doctor accepted your appointment
Next step: Start consultation or check appointment details
```

### Rejected ❌
```
Status: REJECTED [Red Badge]
What it means: Doctor declined your appointment
Next step: Try requesting another appointment with different date/time
```

### Pending ⏳
```
Status: PENDING [Yellow Badge]
What it means: Waiting for doctor to review
Next step: Check back later, or try another doctor
```

## ⚠️ Important Information

### Can I Cancel a Request?
- Yes! You can cancel **pending requests**
- Once approved or rejected, it cannot be cancelled
- Click "Cancel" button if available (for pending only)

### Why Is My Request Pending?
- Doctor hasn't reviewed it yet
- Doctors usually respond within 24-48 hours
- Check back later or try another doctor

### What If Doctor Rejected?
- Don't worry! Try requesting with a different date/time
- Or try a different doctor in the same specialty
- Your rejection doesn't affect future requests

### How Do I Book an Appointment?
- Click "Appointment" in navbar to search and request appointments
- All requests will appear here in "My Requests"

## 🆘 Troubleshooting

### Issue: "My Requests" not showing in navbar
**Solution**: 
- Make sure you're logged in
- Refresh the page
- Clear browser cache
- Login again

### Issue: No requests showing
**Solution**:
- Check if you've made any appointment requests
- Click "Appointment" or "Search" to request one first
- Then come back to "My Requests"

### Issue: Can't see doctor info
**Solution**:
- Scroll down on the card
- Doctor info is at the bottom
- May be below the visible area

### Issue: Filter not working
**Solution**:
- Refresh the page
- Click filter again
- Check if you have requests with that status

### Issue: Page loads slowly
**Solution**:
- Wait for page to load
- Check internet connection
- Refresh if still slow
